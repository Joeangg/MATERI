Tentang CineReview

Platform review film sederhana yang dibuat sebagai bahan belajar HTML, CSS Tailwind, JavaScript, dan PHP.

🎥

Review Film

Baca dan tulis ulasan film favoritmu dengan rating bintang.

▶️

Trailer YouTube

Tonton trailer langsung dari YouTube menggunakan YouTube iframe API.

🎟️

Reservasi Tiket

Pilih film, jadwal, kursi, dan isi data diri untuk reservasi menonton.

💾

Backend PHP

Data review dan reservasi disimpan melalui API PHP sederhana.

📚 Catatan Belajar

Proyek ini dibuat sebagai bahan belajar. Data film dan review disimpan di localStorage (sisi klien) untuk kemudahan penggunaan tanpa server. File PHP disediakan sebagai contoh backend nyata yang bisa digunakan saat belajar lebih lanjut dengan XAMPP atau server lokal.
